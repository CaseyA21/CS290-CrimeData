# How to Run
Simply add all files to a coding environment and run crime_script.py and all data will be wrangled into one combined file in csv format

# CS290-CrimeData
Crime Codes taken from https://ucr.fbi.gov/nibrs/2011/resources/nibrs-offense-codes

# Crime Data Information
Chicago Crime Data from https://catalog.data.gov/dataset/crimes-2001-to-present

Los Angeles Crime Data from https://catalog.data.gov/dataset/crime-data-from-2020-to-present

Philadelphia Crime Data from https://catalog.data.gov/dataset/crime-incidents-285df

# Police Station Information
Chicago Police Station Locations from https://data.cityofchicago.org/Public-Safety/Police-Stations-Map/gkur-vufi

Los Angeles Police Station Locations from https://geohub.lacity.org/datasets/1dd3271db7bd44f28285041058ac4612_0/about?layer=0

Philadelphia Police Station Locations from https://www.pasda.psu.edu/uci/DataSummary.aspx?dataset=7075
